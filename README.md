# 🛡️ Spring Pattern Security

A personal project exploring security patterns, authentication flows and authorization mechanisms in Spring Boot.

The repository contains independent implementations of different security patterns, each in a separate module in the
root directory. Every module is self-contained and runs locally with Docker Compose.

### 🧩 Patterns & Implementations

- [**Authorization Code Flow with PKCE**](pattern-auth-code-pkce/README.md)
